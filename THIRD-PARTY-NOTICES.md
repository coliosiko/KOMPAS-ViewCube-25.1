# Сторонние компоненты

Проекты обращаются к установленным COM API КОМПАС-3D ASCON:
KompasAPI7, Kompas6API5, Kompas6Constants, KompasLibrary, а также Windows stdole.
COMReference настроены с EmbedInteropTypes=True. SDK и отдельные interop-сборки
не включены в этот снимок; разработчик получает их из своей установки КОМПАС.
KAPITypes.dll и исходники KAPITypes из старой истории не включены.

Права на SDK, названия и связанные материалы принадлежат соответствующим владельцам.
Этот документ не предоставляет прав на их распространение. Условия распространения
embedded interop в готовых сборках должны быть проверены перед выпуском бинарников.
