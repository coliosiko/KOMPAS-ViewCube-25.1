KOMPAS ViewCube 1.1 (v25)
===============

Установка
---------
1. Закройте КОМПАС-3D.
2. Распакуйте архив полностью.
3. Запустите install.cmd двойным щелчком и подтвердите запрос Windows.
4. Запустите КОМПАС-3D.
5. Выберите «Приложения» -> «Добавить приложение...».
6. Перейдите на вкладку ActiveX (вкладка RTW для нашей версии не подходит).
7. Выберите «KOMPAS ViewCube 1.1 (v25)» и нажмите кнопку подключения.

После первого подключения приложение появится в меню «Приложения».

Удаление
--------
Закройте КОМПАС-3D и запустите от имени администратора файл
uninstall.cmd из папки:
C:\Program Files\KOMPAS ViewCube

Требования
----------
- Windows x64;
- КОМПАС-3D v25 (x64); версии v24 и другие не поддерживаются;
- .NET Framework 4.8.

Настройка положения
------------------
Откройте настройки и включите «Переместить мышью».
Перетащите куб в удобное место рабочей области. Координаты сохраняются
после отпускания кнопки мыши. Закройте настройки для возврата к навигации.

Обновление
----------
Закройте КОМПАС-3D, распакуйте новую версию в отдельную папку и запустите
install.cmd. Настройки пользователя сохраняются.

Изменения 1.1
-------------
Только v25; плавная SLERP-анимация; выбор ближайшего ровного roll с шагом
90 градусов; перетаскивание положения; собственные векторные стрелки.
